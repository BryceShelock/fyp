② 第三方 API（DeepSeek / OpenAI 兼容代理等）

按顺序：Base URL → Path → 模型名（必须是接口注册的 id） → API Key → 点 Save。 然后再用下方「保存为命名预设」存成方案，之后用下拉 应用到当前 切换（Key 仍留在服务器，不写入预设）。

DeepSeek 报错「Model Not Exist」？ 网页上的「DeepSeek-V3.2」是展示名；API 里要用官方 id： deepseek-chat（对话）或 deepseek-reasoner（思考模式）。

官方 Base：https://api.deepseek.com，Path：/chat/completions（不是 /v1/chat/completions）。Group 请留空。
